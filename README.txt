KAJAL CHaurasiya - PERSONAL PORTFOLIO

FILES
- index.html  : page content and sections
- style.css   : colours, layouts, responsive design (Flexbox + CSS Grid)
- script.js   : navigation, active menu, theme toggle, rotating role, contact form

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html.
4. Right-click in index.html and choose "Open with Live Server", or double-click index.html to open it in a browser.

HOW NAVIGATION WORKS
The Home, About, Skills, Projects, and Contact links point to section IDs (#home, #about, etc.). JavaScript also highlights the active section and closes the menu on mobile.

CUSTOMISE BEFORE PUBLISHING
- Search for "Kajal Chaurasiya" and replace it if needed.
- Replace sample photo URLs with your own photo.
- Replace kajal@example.com and the sample city with your real contact details.
- Replace social profile URLs with your own links.
- Add your resume file and change the "Explore My Work" / resume button as desired.
- Change the example skill percentages to match your actual skill level.
- Update the project descriptions and links.
- The contact form opens an email app. It does not send/store messages by itself.

NOTE
The profile/workspace images and Google Fonts require an internet connection. The project layout works on desktop, tablet, and mobile.
